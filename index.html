Frequently Asked Questions

System Clarifications

How does the video monitoring integration function?

We use secure connection protocol streams to display high-definition security camera live feeds directly inside your primary security smartphone interface [1, 2]. Unlike entirely wireless battery-powered sensors, these premium cameras require standard local power cabling (PoE or 12V adapters) and network runs to function reliably.

How does the system perform during power blackouts?

Every intrusion, fire, and water sensor relies on internal battery cells that remain functional without primary current lines. The Centralized Hub automatically shifts to independent 16-hour backup cells. High-definition security cameras require a separate local uninterruptible power supply (UPS) to stream during local power outages.

Can standard wireless signals be scrambled or jammed?

The centralized core automatically recognizes external signal interference. If communication jamming attempts are registered, the system dynamically shifts operating frequencies and instantly broadcasts alerts to monitored dispatch operators.

Is a physical recorder mandatory for camera feeds?

No. High-definition live video feeds stream directly to your primary application dashboard without a separate recorder. If continuous offline recording archives are required, a network video recorder (NVR) can be added as a separate line item.
